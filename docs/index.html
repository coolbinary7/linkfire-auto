Linkfire Auto
Code source
Extension Chrome · Pre-save

Tes liens pre-save Linkfire, en série.

Tu donnes l’artiste, le titre, l’UPC et la date de sortie (ou un fichier Excel avec plusieurs sorties). L’extension crée chaque lien dans Linkfire, programme le rescan à la date de sortie, publie, puis te rend tous les liens à copier.

Version actuelle
1.5.3
Télécharger l’extension Modèle Excel des sorties

À installer sur un ordinateur où Linkfire est déjà accessible et connecté dans Chrome.

Installation (une seule fois)

  1. Télécharge le zip et dézippe-le : tu obtiens un dossier linkfire-auto. Range-le à un endroit où il ne bougera pas.
  2. Dans Chrome, ouvre chrome://extensions.
  3. Active Mode développeur (en haut à droite).
  4. Clique sur Charger l’extension non empaquetée et choisis le dossier linkfire-auto.
  5. Épingle l’extension (icône puzzle 🧩), puis clique dessus : le panneau s’ouvre sur le côté.

Si « Mode développeur » est grisé, l’ordinateur bloque les extensions : demande à l’IT de l’autoriser.

Utilisation

1. Importer

Sur la page d’une sortie RWS, clique « Scanner l’onglet RWS ouvert » (ou scanne tous tes onglets RWS d’un coup). Sinon : modèle Excel, copier-coller ou saisie à la main.

2. Vérifier

Contrôle le lien proposé : Artiste1xArtiste2.lnk.to/titre (3 caractères minimum après le /). Tu peux le modifier.

3. Lancer

Garde Linkfire connecté dans un onglet. Laisse tourner, puis copie tous les liens ou exporte-les en CSV.

  • Mode Guidé : l’extension attend ton « Continuer » avant chaque étape. Conseillé pour un premier essai.
  • En cas de blocage, un bandeau en bas à gauche de Linkfire explique quoi faire : Réessayer, faire l’étape à la main puis continuer, ou Passer ce titre.
  • Le bouton Copier le diagnostic copie l’état de la page pour signaler un problème.
  • Les zéros au début des UPC sont gardés, même si Excel les a enlevés.

Mise à jour

  1. Télécharge la nouvelle version et remplace l’ancien dossier linkfire-auto par le nouveau.
  2. Dans chrome://extensions, clique sur la flèche ↻ de Linkfire Auto.
